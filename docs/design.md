# 数据与算法设计

`Poset` 保存行主序的自反传递关系及按前驱数量稳定排序的线性扩张。严格前驱的数量必然更小，因此该排序满足偏序。公开构造器要么计算闭包并拒绝环，要么完整校验输入矩阵。局部编号保留调用方的语义，API 不假定 x<y 的数值大小。

`Kernel` 只允许可比区间上的 Int64 系数。矩阵三角递推计算单位逆；ζ 的逆就是一般偏序 Möbius 核。每次乘法和求和均检查范围。左／右方程通过逆卷积解决；向量求解无需构造完整逆。对偶会交换乘法次序，任意子集限制通常不是代数同态。

下闭集 `Ideal` 保存独立的成员位数组。只有所有严格前驱已在集合内，元素才可加入；只有没有严格后继留在集合中，元素才可删除。交并保留下闭性。历史枚举按可加入元素的数字顺序回溯，排名也使用这一词典顺序。计数器对已加入的掩码缓存后续历史数，预算按不同状态计费，包含满集。

链分解通过严格序的二分图最大匹配实现。未匹配右节点是链起点；交替可达集给出最小顶点覆盖的补集，从中取最大反链。测试同时检查链划分覆盖每个顶点一次、反链独立且两个证书基数相同，并用独立子集穷举核对最优值。

序多项式按标签层增加下闭集。弱映射允许任意嵌套下闭集；严格映射要求每层新加入的差集是反链。先构造允许转移，再按标签数累计。空层允许，因此计算的是标签映射数，不是满射数。

# 安全和资源责任

库不联网、不访问文件、不执行外部进程，也不使用随机源。输入大小上限和溢出检查是语义约束。枚举返回前复制结果；调用者修改返回数组不会改变已有值。预算限制搜索或转移的计数，单次计费内可能包含 O(n²) 的循环；它不是时间上限、线程取消或内存隔离。对不可信请求，宿主仍需限制并发、请求大小和总运行时间。

未包含解析器、序列化协议、并发可变状态或持久化格式。公共 API 以生成接口为准。未来若改变编号、预算、异常或整数溢出语义，需要明确版本变更。
